SystemVerilog Elevator Controller

Course Digital Logic Design II · April 2025
Status Complete
SystemVerilog ModelSim Quartus II FSM Digital Logic 7-Segment Display Debouncing
Overview

Designed and simulated a 4-floor elevator control system entirely in SystemVerilog. The system handles floor requests from both inside and outside the elevator, directional movement logic, door control, and a 7-segment display showing current and desired floors. Verified in ModelSim with timing analysis across multiple test scenarios.

State Machine Design

The elevator logic is structured as a finite state machine with the following states:

IDLE
Waits for a floor request input.
UP
Moves up one floor at a time when current floor is below desired.
DOWN
Moves down one floor at a time when current floor is above desired.
fetchDF
Fetches a new desired floor once current equals desired.
inside
Handles internal button requests from inside the elevator.
outside
Handles external button requests from outside the elevator.

Challenges

Button debouncing was a key hardware challenge — physical buttons caused multiple triggers per press, requiring a software debounce module. Clock speed also needed to be slowed down to allow smooth LED transitions visible to the eye. FSM edge cases required careful handling, especially when the current floor and desired floor were equal.
