Pulse Width Modulator Circuit

Course Circuits II · August 2025
Status Complete
555 Timer IC LTspice Analog Design Oscilloscope Potentiometer Diode Logic
Overview

Designed and built a pulse width modulator circuit using a 555 timer IC. The circuit produces a square wave with a variable duty cycle controlled by a single potentiometer — without significantly changing the output frequency or amplitude. Output was validated with an oscilloscope and results matched LTspice simulations closely.

Key Components
555 Timer IC
Generates the square wave output based on charge/discharge timing.
10kΩ Potentiometer
Acts as a variable resistor. Rotating it changes the duty cycle.
2 Diodes
Separate charge and discharge paths, enabling independent duty cycle control.
Capacitors
2.2nF and 0.68µF caps store charge to control timing intervals.
How It Works

The potentiometer splits into two resistances R1 and R2. The diodes route current through R1 during charging and R2 during discharging, so adjusting the pot changes their ratio. A higher R1 means a longer ON time (higher duty cycle). Because R1 + R2 stays constant, the output frequency stays nearly fixed while only the duty cycle changes.

Results

Oscilloscope measurements confirmed the circuit produced accurate duty cycles at 25%, 50%, and 75% matching the LTspice predictions. Frequency remained stable across all potentiometer positions, validating the diode-separated charge path design.
